# Data sources

`updates.jsonl` holds real version pairs of the public packages below, with their public GitHub release notes
(each record links to the releases it quotes in `release_urls`) and public GitHub Advisory Database entries.
Release notes are quoted unchanged, apart from trimming, under each project's licence.
The CI results and the repository files in `labels.jsonl` are invented for the evaluation.
